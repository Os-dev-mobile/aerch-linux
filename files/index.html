Aerch Linux

An Arch-based desktop with KDE Plasma and a graphical installer. The beta is out now.

Download the beta View on GitHub

The official release is planned for December 2026.

What you get

Arch underneath

Built on Arch Linux, so you get rolling updates and the Arch package ecosystem.

KDE Plasma desktop

A full Plasma desktop on the live ISO, ready to try before you install.

Graphical installer

Install to your disk with Calamares. Open the installer from the desktop.
